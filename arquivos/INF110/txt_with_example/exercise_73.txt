Horário
Faça um programa para ler um horário no formato 24 horas e escrevê-lo no formato HH:MM AM/PM. Para escrever o horário você deve utilizar obrigatoriamente uma função com o seguinte protótipo:
language=C++,
                basicstyle=,
                keywordstyle=,
                stringstyle=,
                commentstyle=,
                morecomment=[l][]#,
                basewidth = .48em
void escreve (Horario h);
onde  é um tipo definido da seguinte forma:
language=C++,
                basicstyle=,
                keywordstyle=,
                stringstyle=,
                commentstyle=,
                morecomment=[l][]#,
                basewidth = .48em
struct Horario 
  int horas, minutos;
;
Entrada:
A primeira linha da entrada contém um número N, indicando que haverá N casos de teste. As N linhas seguintes contêm um caso de teste cada, que são dois inteiros H e M, respectivamente o número de horas e minutos. Restrições: 0 ≤ H ≤ 23, 0 ≤ M ≤ 59.
Saída:
Seu programa deve gerar N linhas de saída, uma para cada caso de teste da entrada, com o horário no formato desejado.
Exemplos:
6
10 20
22 20
12 0
0 0
12 5
13 0
10:20 AM
10:20 PM
12:00 PM
12:00 AM
12:05 PM
01:00 PM
