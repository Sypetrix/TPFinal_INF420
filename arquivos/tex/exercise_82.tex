\begin{problem}{Número Primo}{primo}{2}
 
Um número natural $N > 1$ é um número \textbf{primo} se ele é divisível apenas por $1$ e por $N$.

Faça um programa que verifica se um dado número é primo.

%\Notes
%
%Observações, se tiver.

\InputFile

A entrada contém um único valor inteiro $N$. Restrições: $1 < N \leq 1000$.


\OutputFile

Seu programa deve escrever apenas uma linha na saída, contendo o texto ``\texttt{Primo.}'' caso $N$ seja primo ou o texto ``\texttt{Nao primo.}'' caso contrário.

Atenção ao ponto final e à ausência de acentuação.

\Example

\begin{example}
\exmp{
3
}{
Primo.
}%
\end{example}

\begin{example}
\exmp{
33
}{
Nao primo.
}%
\end{example}


%Comentários sobre o exemplo, se necessário.

\end{problem}
